## Featured project: Clinical Trials Intelligence

**PostgreSQL · SQL · Power BI · DAX**

An analysis of industry-led interventional drug and biological trials using ClinicalTrials.gov / AACT data, with a global view and a UK focus.

I investigated **12 stakeholder questions**, prepared trial-level data, modelled multinational participation and built **three Power BI dashboard pages**:

- **Trial Overview:** activity, status, phase mix and country participation.
- **Portfolio & Delivery Insights:** enrollment, site footprint and recorded timelines.
- **Geographic & Reporting Governance:** UK participation and public results visibility.

### What the analysis found

| Finding | Why it matters |
| --- | --- |
| Phase 3 median recorded enrollment was **312**, compared with **36** in Phase 1; median site counts were **24 versus 1**. | Highlights differences in recruitment and coordination requirements. |
| UK participation was **17.6% for 2015 starts** and **12.8% for 2025 starts**, among trials with known geography. | Provides a starting point for geographic benchmarking. |
| Mature eligible results coverage was **18.2% in Phase 1** and **71.3% in Phase 3**. | Shows uneven public evidence availability; it does not establish regulatory non-compliance. |

The repository includes the SQL research, Power BI report, DAX measures, supporting data, validation evidence and limitations. A separate **200-study Python/pandas API workflow** demonstrates ingestion and nested-data preparation.

## How I approach analysis

- Start with a clear question, population and unit of analysis.
- Check keys and relationships before joining tables.
- Validate counts, missingness and percentage denominators.
- Distinguish observed patterns from causal explanations.
- Document assumptions, source limitations and reproduction steps.
